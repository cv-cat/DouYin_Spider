抖音主页公开性别清洗工具

首次使用：
1. 双击“第1步_扫码登录.bat”。
2. 在打开的抖音网页扫码登录，程序检测成功后会自动保存到 browser_profile。
3. 登录资料只保存在本机工具目录，不写入 YML。

登录后并发试跑：
1. 双击“第2步_登录后试跑5个.bat”。
2. 浏览器会直接复用 browser_profile，不再要求重复扫码。
3. 默认同时打开 5 个标签页，由程序自动把不同用户分发给空闲标签页。
4. 本步骤试跑 20 个用户，只识别并显示公开性别，不删除评论、不修改 YML。
5. 不需要手工把 YML 拆成 5 份；动态分配比固定五等分更快，某个主页加载慢时不会拖住整份数据。
6. 第一轮并发访问失败的主页，会自动进入单标签低速补扫，避免限流造成漏查。

识别规则：
1. 第一优先级：只在公开资料栏性别图标中读取 SVG 颜色。
   - fill="#168EF9" 判定为男。
   - stroke="#F5588E" 判定为女。
2. 第二优先级：颜色未命中时，再读取资料栏 .rTzhSEM4 子节点中独立出现的“男”或“女”。
3. class 变化时，在抖音公开主页资料栏内寻找独立的“男”或“女”文本。
4. 不扫描页面其他 SVG，不把按钮等蓝色、粉色元素误判为性别。
5. 不把“男朋友”“女生”等内容中的单个字误判为公开性别。
6. 之前缓存为“未知”的主页，登录后会自动重新检查。

正式清洗（确认识别准确后再运行）：
.venv_runtime\Scripts\python.exe clean_douyin_gender.py --tabs 5

若抖音出现 HTTP 403：
双击“第3步_3标签正式清洗50个.bat”。该模式使用 3 标签、2 秒错峰、每标签至少 5 秒访问间隔，并对失败页面低速补扫。

正式清洗只有明确识别为“男”才会删除，并会先自动备份 YML。

依赖说明：当前使用 .venv_runtime 复用本机已安装并验证可用的依赖。
