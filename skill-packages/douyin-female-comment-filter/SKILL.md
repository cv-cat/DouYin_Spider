# 抖音评论区女生筛选

## 目标

从抖音视频一级评论中筛选 IP 属地为湖北、且公开证据未表明为男性的评论者。最终只交付一个清洗完成的 YML 文件。

## 必须读取

- 开始抓取前阅读 [references/project-map.md](references/project-map.md)，确认本机项目与入口仍存在。
- 写最终文件前阅读 [references/final-yaml.md](references/final-yaml.md)。
- 执行清洗时阅读 [references/cleaning-rules.md](references/cleaning-rules.md)。

## 触发与输入

当用户消息包含抖音链接，并表达“筛选女生评论”“湖北IP女生”“找女性评论者”等意图时启动。

1. 验证链接属于 `douyin.com` 或 `v.douyin.com`。
2. 若没有目标数量，先问：“需要抓取多少条符合条件的一级评论？”
3. 数量必须为正整数。视频实际可用评论不足时，抓取全部可用评论，不报错凑数。
4. 只抓一级评论；不抓二级回复、楼中楼或追评。

## 第一轮：抓取与内容清洗

1. 优先使用项目17现有逆向抓包/API流程，禁止用Playwright滚动评论区代替抓包。
2. 解析视频ID，分页抓取一级评论，保留评论ID供内部去重，但最终YML不输出评论ID。
3. 获取并保留：日期、昵称、评论内容、IP、主页链接、主页获赞数、粉丝量。
4. 只保留 `IP: 湖北`。
5. 按 [references/cleaning-rules.md](references/cleaning-rules.md) 删除明确男性、高度可信男性及不符合年龄/地域规则的数据。不确定时保留。
6. 第一轮完成后告知用户清洗数量，并提供阶段文件链接。
7. 明确询问用户是否继续第二轮公开主页性别核验。未经确认不得启动浏览器批量访问。

## 第二轮：公开主页性别核验

仅在用户确认后执行。

1. 使用项目17的 `scripts/clean_douyin_gender_playwright.py` 或桌面同版工具。
2. 复用用户主动扫码保存在本机 `browser_profile` 的登录状态；不得输出或复制登录凭证。
3. 使用3个有头标签页低频运行：首次错峰2000ms，每标签访问间隔至少5000ms。
4. 识别优先级：
   - 资料栏性别图标内 `fill="#168EF9"` → 男。
   - 资料栏性别图标内 `stroke="#F5588E"` → 女。
   - 颜色未命中，再读取资料栏独立文本“男”或“女”。
5. 仅在公开资料栏范围判断，禁止扫描页面任意蓝色/粉色SVG。
6. 明确为男：删除。明确为女：保留并归入“已公开性别为女”。未公开或无法确认：保留并归入“未公开性别”。
7. HTTP 403、验证码、登录失效、页面加载错误不得视作未知并结束，更不得删除；停止高频访问，冷却后低速补扫。持续失败则保留并在运行报告说明。

## 最终输出

1. 使用 `scripts/build_final_yaml.py` 将第二轮结果整理为唯一最终版YML。
2. 顶部总览只保留：
   - 视频一级评论总数
   - 湖北IP评论数
   - 累计清洗删除数
3. 先输出“已公开性别为女”，再用醒目注释分隔，最后输出“未公开性别”。
4. 每条记录之间空两行；全部字段使用中文。
5. 不输出 Comment ID、删除审计、清洗历史、内部选择器、Cookie或断点数据。
6. 最终只向用户提供一个最终YML链接；日志和备份仅在用户要求时提供。

## 安全与准确性

- 不根据头像推断性别。
- 单一兴趣、昵称风格或身高不得单独证明性别；按规则组合判断。
- 不虚构主页数据。
- 不绕过验证码、403或平台权限。
- 原始抓取文件先备份；第二轮写入新文件，不覆盖用户指定的源文件。
- 输出前验证：最终保留数 + 累计删除数与输入范围一致，且分区数量与记录数一致。
